# ADR 0090 — Derived offline canonical symbol qualification

Status: implemented, independent technical acceptance pending. CODEX-007, Prompt22.

P20 retains economic identity/taxonomy/revision/resolution authority. P21 retains raw namespace,
catalogue/B1 and selector-specific proposal/decision authority, including its accepted Q-SELECTOR
qualification. A new package is preferable to changing that accepted selector-specific lifecycle:
P22 owns whole-observation consistency, cross-broker groups, immutable mapping sets and
reconciliation. Architecture was recorded before creating code in the external development evidence.

All material supplied claims are resolved through the public P20 resolver on an exact retained view
constructed by public P21 registryView for ordinary research histories. Recognized verified
histories use a small adapter to the existing P20 constructor/verifier contract, because the P21
helper does not expose a verifier parameter. No owner interface is changed or new resolver/verifier
created. Every result, no-match, ambiguity, policy exclusion and contradiction is retained. No names
or comparison keys establish identity; P21 B1 keys are reused without extending prefix grammar.
Independently qualified groups use real canonical IDs/revisions. Name collisions across distinct IDs
are explicit evidence and never merge economic groups. Identity qualification does not establish
identical contract specifications or trading suitability.

Policy uses existing BROKER configuration key broker.mapping.policyJson. State domain
canonical.mapping is DERIVED/RESEARCH and mutation-validated by the existing persistence authority.
Immutable FS adapter follows accepted exclusive-publication/readback contract; no new global
durability authority, fsync, power-loss or Windows claim. UNKNOWN retains exact attempted
generation/hash and unsuccessful stop. Recovery reconstructs actual retained owner evidence at
stored clock/context/policy, preserving all prefixes. Historical policy compatibility must be
explicitly listed in current governed policy.

P21 does not expose strike/right/network/share-class/maturity observations in its raw contract. P22
accepts separately referenced/hash-bound supplemental assertions for contradiction assessment, never
as sufficient identity evidence or a replacement for P21 raw records. P20's identity parser owns
canonical discriminator/decimal semantics. Lack of a prefix operation and missing stronger origin/
contract certifications remain explicit gaps; no upstream owner change is introduced.

Human approval remains P21-only. Research association requires current P22 uniqueness and actual P21
approval for the exact target/revision. There is no new checker, certificate or governance
lifecycle. All P20/21 conditions, F05/F06/T01/M02/O-C01/O-C02/Q01-A, Q-HIST/Q-TICK/Q-SELECTOR/Q-T01
and historical failed assertions remain intact. Prompt22 completion is not acceptance; Prompt23 not
authorized.
