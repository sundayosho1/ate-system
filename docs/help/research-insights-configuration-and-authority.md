# Configuration guidance and authority

The foundation explains settings; P7–P12 remain the only
schema/resolution/version/capability/approval/release authorities. It cannot register a domain/key,
activate flags, grant permissions, promote, roll back or supply effective configuration. Metadata
identifiers beginning policy.* are documentation grouping only, not accepted configuration keys.

Every ConfigurationGuide identifies owner/key/schema/field path, type/unit/default/bounds,
scope/override/dependency, risk/restart/authority and source references. UNKNOWN means
declaration/effective evidence is unavailable. A raw schema line is explanatory bounds evidence, not
an independent policy evaluator. Multiline and cross-field constraints require the full linked
public source contract; no inferred defaults. Candidate, versioned, approved, active and
restart-pending values are different facts.

User: read purpose/workflow and source qualifications. Administrator: use genuine existing
actor/policy/exact-version approvals; persona is not authority. Developer: public package roots
only, no private imports or live queries. Troubleshooting: retain native Results, original
ID/payload, NONE/UNKNOWN/ACK and current/historical distinctions; no automatic refresh/recovery.
Historical approval does not prove current eligibility.

R1 is immutable foundation policy data, not a newly registered configurable setting.
validateResourceProfile rejects any changed field/value. No option may increase the approved
ceilings. Full active/future-only bounds, byte units and errors are in
research-insights-foundation.md. Unknown cost bounds deny later live adapters; timeout is never
proof of cancellation/NONE. New schemas cannot replace accepted owner authority.

No secret references are dereferenced. Export fields are inert text, not HTML/actions. Supplied
source hashes attest byte identity only; they are not authenticated broker statements or independent
validation. No IAM, credentials, network listener, live connectivity, financial execution or
production claim is provided.
