# Offline opportunity lifecycle

`@ate/mose-opportunities` owns the Prompt 28 historical opportunity state machine. Technical and
governance acceptance remain pending. This package supplies bounded offline research functions, with
no broker, network listener, execution or production capability.

Start with [user help](../../docs/help/mose-opportunities.md),
[administration](../../docs/help/mose-opportunities-administration.md),
[developer contracts](../../docs/help/mose-opportunities-developer.md),
[glossary](../../docs/help/mose-opportunities-glossary.md) and
[architecture](../../docs/architecture/mose-opportunities.md).

The public root exports strict input validation, deterministic identity, pure evaluation, an
explicit runtime, memory and optional filesystem repositories, qualified diagnostics, local reports
and pull handoffs. Raw JSON context alone cannot authorize a decision: a reviewed trusted host must
supply captured native evidence and verify the exact actor, source, policy, configuration and
approval scope. P5 domain ownership registration is not actor authentication.

Historical opportunity labels never grant trading authority. P29 ranking and P30 reconciliation are
unavailable. Native P28 integration into accepted P1–P27 reporting/workspace owners remains
UNSUPPORTED; this package supplies standalone projections.
