# @ate/mose-core

Deterministic bounded offline research surveillance, immutable universes, evidence-qualified
observations, coverage accounting and checkpoint/recovery. No strategy signals or execution
authority.

See [MOSE help](../../docs/help/mose-core-surveillance.md) for public composition, governed policy,
resource bounds, lifecycle, temporal/provenance contracts, reports, shutdown and recovery. Prompt25
implementation requires independent technical and governance review; Prompt26 is not authorized.
